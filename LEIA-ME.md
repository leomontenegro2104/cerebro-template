# Como montar seu segundo cérebro

1. **Contas e instalação**: GitHub (ative 2FA), Claude Pro + app Claude desktop, Obsidian, GitHub Desktop.
2. **Repositório**: descompacte esta pasta onde quiser. No GitHub Desktop: *File → Add local repository* → escolha a pasta → *Publish repository* com **Keep this code private** marcado.
3. **Obsidian**: *Open folder as vault* → esta pasta. Quando perguntar, confie no autor e ative os plugins da comunidade (o Obsidian Git já vem configurado: salva a cada 15 min e puxa ao abrir).
4. **Web Clipper**: instale a extensão Obsidian Web Clipper no navegador e defina a pasta de destino `inbox/clips`.
5. **Primeira conversa**: no app Claude, aba **Code**, abra esta pasta e diga *"vamos fazer o setup do vault"*. Ele pergunta seu nome, suas áreas e faz uma entrevista para te conhecer.

## Rotina
- Salvou artigo/vídeo/PDF → cai em `inbox/` → rode `/ingest`.
- Fim de uma conversa boa → `/salvar`.
- Uma vez por semana → `/revisao-semanal`.

## Regras
- Nunca coloque senha, CPF ou número de conta nas notas.
- `me/` é seu: a IA só mexe quando você pede.
