# MAP — índice global

Leia primeiro. Cada área tem seu próprio `MAP.md`.

| Caminho | O que tem |
|---|---|
| [[hot]] | Foco atual, pendências e prazos (curto, sempre atual) |
| [[decisoes]] | Decisões gerais com data e motivo |
| [[log]] | Changelog do que a IA alterou |
| `me/` | [[user]] quem eu sou · [[soul]] quem a IA é · [[anti-slop]] estilo proibido |
| `inbox/` | Material bruto aguardando `/ingest` |
| `raw/` | Material bruto já processado (imutável) |
| `daily/` | Notas diárias `AAAA-MM-DD.md` |
| `pessoas/` | Uma nota por pessoa |
